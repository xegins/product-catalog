# Каталог товаров

Статический каталог из архива «Новая папка (3).zip»: 30 товаров, поиск и фильтры по категориям. В комплекте 32 фотографии JPEG. Кнопок и формы заказа в исходном HTML нет.

Сайт: https://xegins.github.io/product-catalog/

Откройте index.html в браузере или опубликуйте содержимое через GitHub Pages из ветки main, папка / (root).
