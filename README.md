# Каталог товаров

Статический каталог на основе HTML-файла `Qwen_html_20261003_erwiqde8l.html`: 30 товаров, поиск и фильтры по категориям. Цены и форма заказа в исходном HTML не предусмотрены.

Сайт: https://xegins.github.io/product-catalog/

Два товара без фотографий — вертикальный пылесос и цепная электропила — исключены по просьбе владельца сайта. Остальные карточки используют фотографии из предыдущего комплекта. Локальная заглушка `assets/no-image.svg` сохранена на случай ошибки загрузки изображения.

GitHub Pages публикует содержимое ветки `main` из корня репозитория.
