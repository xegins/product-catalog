# Каталог товаров

Сайт: https://xegins.github.io/product-catalog/

Репозиторий: https://github.com/xegins/product-catalog

Новая версия из архива `Новая папка (2).zip`: 30 товаров, поиск и фильтры по категориям. Все 32 JPEG из архива включены в сайт; 30 из них используются в карточках. Кнопок и формы заказа в новом HTML нет.

Главная страница — `index.html`. Содержимое, цены и оформление нового HTML сохранены; внешний сервис заглушек заменён локальным файлом `assets/no-image.svg`.

## Обновление

Обновляйте файлы в ветке `main`. GitHub Pages автоматически публикует содержимое корня репозитория. Файл `.nojekyll` отключает обработку Jekyll; установка зависимостей и сборка не нужны.
