# Каталог товаров

Статический сайт из предоставленного HTML: 27 товаров, поиск, фильтры по категориям и окно заказа. HTML, CSS и JavaScript находятся в `index.html`; установка зависимостей и сборка не нужны.

## Публикация через GitHub Pages

1. Создайте репозиторий GitHub, например `product-catalog`. Для бесплатного GitHub Pages на GitHub Free нужен публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория: `index.html`, `.nojekyll`, `README.md`, все 27 файлов `.jpg` и папку `assets`.
3. Откройте **Settings → Pages**.
4. Выберите **Source → Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Дождитесь завершения публикации. Адрес будет показан на странице Pages; для репозитория `product-catalog` обычно это `https://<ваш-логин>.github.io/product-catalog/`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Состояние исходного документа

- Подключены все 27 фотографий из предоставленного архива; их имена соответствуют полям `image` в массиве `products`.
- При ошибке загрузки фотографии используется локальная заглушка `assets/no-image.svg`.
- Для замены фотографии обновите соответствующий файл `.jpg` рядом с `index.html`, сохранив его имя.
- Форма заказа демонстрационная: она показывает сообщение, но не отправляет заявку продавцу. Для реальных заказов потребуется отдельно подключить способ отправки.

Содержимое, цены и оформление исходного HTML сохранены. В обработчике отсутствующих фото внешний сервис заменён локальной заглушкой; повторная обработка ошибки отключена.
